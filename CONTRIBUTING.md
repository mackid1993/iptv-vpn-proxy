# Contributing

This project was made for personal use. It is shared as is, free, with no
expectation of support, in case it is useful to someone else.

- **Issues are turned off.** Bug reports and feature requests are not taken.
- **Pull requests are not accepted.**
- **Questions will not be answered.**

You are welcome to use it, copy it and change it for yourself under the
[MIT license](LICENSE). If you want it to work differently, fork it and make
it yours.

Everything needed to set it up and run it is in the [README](README.md).
